# SENG383-SECTION1-G4
AI-Assisted Child Development Platform – SENG 383 term project (Fall 2026)

## Running locally

### Frontend (React + Vite)

```bash
cd client
npm install
npm run dev
```

The page opens at http://localhost:5173. Requests to `/api` are forwarded to the backend at http://localhost:3000, so start the backend first.
